Minishell — A Minimal Bash Clone
Minishell is a small Bash-like shell written in C as part of the 42 curriculum. It handles command execution, pipes, redirections, environment variables, and includes built-in commands.

Features:
   Interactive prompt
   History support
   Redirections: <, >, <<, >>
   Pipes (|)
   Environment variable expansion ($VAR, $?)
   Quoting rules with ' and "
   Signals (Ctrl+C, Ctrl+D, Ctrl+\)
   Built-ins: echo, cd, pwd, export, unset, env, exit
